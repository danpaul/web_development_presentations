# Final quality checklist

Before sending the report, confirm each item.

## Coverage
- [ ] The Marp markdown was read directly. An HTML or PDF export was not used in its place.
- [ ] Every slide was inspected or omissions are listed. Slide numbers follow source order after the frontmatter.
- [ ] Speaker notes (prose HTML comments) were inspected. Directives, frontmatter, and `<style>` blocks were not treated as claims.
- [ ] Factual images, code fences, tables, and material links were considered.
- [ ] Each factual claim has a stable claim ID.
- [ ] Compound claims were split where needed.
- [ ] Every claim has a verdict or an explicit unreviewed status.

## Evidence
- [ ] Relevant source pages were opened, not just discovered in search results.
- [ ] Each URL points to the source actually used.
- [ ] The cited passage supports the exact wording and context.
- [ ] Source authority, date, version, scope, and limitations were considered.
- [ ] High-impact or disputed claims have appropriate corroboration.
- [ ] Conflicting evidence is reported.
- [ ] No citation, quotation, date, or statistic was fabricated.

## Verdicts
- [ ] “Unverified” is not confused with “Contradicted”.
- [ ] “Verified” is not based solely on repetition or a weak source.
- [ ] Current claims were checked against relevant current documentation.
- [ ] Opinion and predictions are not falsely presented as objectively verifiable facts.
- [ ] Confidence and severity are recorded separately.

## Recommendations
- [ ] Suggested wording preserves the original teaching intent where possible.
- [ ] Replacement text does not introduce unchecked claims.
- [ ] High-stakes findings are flagged for expert review where appropriate.
- [ ] Suggested wording is drop-in markdown for the same construct.
- [ ] The source markdown was not modified unless the user explicitly asked.

## Reporting
- [ ] Summary counts match the final claim ledger.
- [ ] Coverage limitations are prominent.
- [ ] Sources are deduplicated and traceable.
- [ ] The report is understandable to a reader who did not perform the research.
