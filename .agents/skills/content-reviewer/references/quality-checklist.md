# Final quality checklist

Before sending the report, confirm each item.

## Coverage

- [ ] The Marp markdown was read directly. An HTML or PDF export was not used in its place.
- [ ] Every slide was inspected, or omissions are listed. Slide numbers follow source order after the frontmatter.
- [ ] Speaker notes were considered. Frontmatter, `<style>` blocks, and Marpit directives were not treated as content.
- [ ] Every slide appears in the topic inventory or in the coverage section.
- [ ] The report states the inferred audience and lesson scope before the findings.

## Research

- [ ] Each key topic was researched, or the report says which topics were not.
- [ ] Relevant source pages were opened, not just discovered in search results.
- [ ] Each URL points to the source actually used.
- [ ] The cited passage supports the currency or coverage judgment, not a nearby topic.
- [ ] No citation, quotation, date, or version was fabricated.
- [ ] If web access was unavailable, the report is labelled as a preliminary review and does not claim the topics were checked for currency.

## Judgments

- [ ] Currency, missing topics, and cuts are separated.
- [ ] Missing topics are limited to what this lesson needs. The deck is not padded with the whole ecosystem.
- [ ] A factually true aside is still eligible to cut when it does not serve the lesson.
- [ ] A claim-level factual dispute is noted for `fact-checker` and is not given a fact-check verdict here.
- [ ] Suggested sketches do not introduce unverified factual claims. Unverified additions say they need a fact-check before use.

## Reporting

- [ ] Summary counts match the inventory and the findings.
- [ ] Coverage limitations are prominent, including the note that this was not a claim-level fact-check.
- [ ] Sources are deduplicated and traceable.
- [ ] The report is understandable to a reader who did not perform the research.
- [ ] The source markdown was not modified unless the user explicitly asked.
