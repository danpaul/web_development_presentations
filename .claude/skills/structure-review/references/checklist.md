# Final checklist

Before sending the report, confirm each item.

## Coverage

- [ ] The Marp markdown was read directly. An HTML or PDF export was not used in its place.
- [ ] Every slide was inspected or omissions are listed. Slide numbers follow source order after the frontmatter.
- [ ] Speaker notes were read for transitions. Directives, frontmatter, and `<style>` blocks were not treated as slides.
- [ ] The deck map has one role per inspected slide.
- [ ] The through-line is one sentence about the journey, not a grade of the material.

## Scope

- [ ] Findings are only about through-line, sequence, repetition, transitions, or clarity of role.
- [ ] No finding judges accuracy, depth, interest, or how well a point is explained.
- [ ] No finding comments on spelling, grammar, voice, code correctness, visual design, theme, fragments, or image quality.
- [ ] A repeat that previews, gives another example, calls back, or recaps is not flagged when it has a new role.
- [ ] Both locations are cited for every repetition.
- [ ] A topic change is flagged only when no section slide, heading, linking first line, or speaker note bridges it.
- [ ] A finding that would need a fact check or a prose rewrite names the boundary and stops.

## Recommendations

- [ ] Each finding has one move: reorder, merge, cut, add a bridge, or retitle.
- [ ] Suggested moves contain no replacement lesson text.
- [ ] The source markdown was not modified unless the user explicitly asked.
- [ ] If edits were applied, they are structural only, and each edit is listed with its finding ID.

## Reporting

- [ ] Findings are ordered by severity, then slide number.
- [ ] The suggested move list matches the findings and follows deck order.
- [ ] Coverage limits are stated in the scope section.
- [ ] A clean deck is reported as clean. Issues are not invented to fill the report.
